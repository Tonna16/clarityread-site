ClarityRead — Reading Mode & Dyslexia Support

Toggle dyslexia-friendly fonts, reflow text, contrast, and read-aloud — all locally in your browser.

Turn cluttered web pages into calm, readable text in one click.

ClarityRead helps you read with less friction: accessible dyslexia-friendly fonts, focus-first page cleanup, private local controls, and instant reader tools that keep pace with your browsing.

Install on Chrome See features
Private by default · Works instantly · Built for dyslexia-friendly reading

Key features

Dyslexia font
Switch to OpenDyslexic-style font for easier character recognition.
Reflow & reader
Reformats long articles into a readable column with adjustable font sizes.
Read-aloud
Uses your browser's speech synthesis — no text is sent externally by default.
High contrast
Toggle high-contrast and invert modes for better visibility.
